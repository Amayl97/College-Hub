# College Hub — Things They Don’t Tell You

> A student-built digital space for the things college websites usually don't tell you.

**College Hub** is a frontend-only college resource website designed around the real experiences of students at affiliated colleges. It brings together academic resources, previous papers, college guidance, useful links, temporary updates, and the small experiences that make college life memorable.

The project was created for the **Codédex Back 2 School Builds** challenge.

---

## 🌱 Why I Built This

College can be difficult for reasons that have nothing to do with coursework.

As a student at an affiliated college, I noticed that we don't have a dedicated student portal where everything is organized in one place. Notes, previous-year papers, announcements, resources, and practical advice are often scattered across class groups, messages, teachers, classmates, and personal files.

This becomes especially challenging under the **University of the Punjab (PU)** system, where previous papers and notes can be important for exam preparation, while university examinations can sometimes be difficult to predict.

There is also a lot of practical knowledge that students simply learn through experience.

**College Hub** is my attempt to put some of that information into one place — while making it feel more like a student's space than a traditional college website.

---

## ✨ What’s Inside

### 📝 Notes

A central place for course notes and study material so students don't have to search through scattered files and class groups.

### 📄 Past Papers

A collection of previous examination papers to help students understand past exam patterns, topics, and expectations.

### 🗓️ Semester Timeline

An interactive visual timeline showing the semester as a journey rather than just a list of dates.

### 📌 Tea Room

A digital version of a college notice board for temporary announcements, updates, and useful information.

### 💭 Rant

A private space where students can write whatever is frustrating them.

The idea is simple:

**Write it → Let it out → Let it go.**

The rant isn't stored in a database or sent anywhere. It exists only while the page is open and disappears when the student lets it fly away.

### 🌱 Beyond College

A collection of resources that encourages students to explore learning opportunities beyond their regular college coursework.

Resources are organized according to department and year so students can discover things relevant to their current stage.

### 🗺️ College Survival Map

A collection of practical knowledge about college life — the things students usually learn from experience rather than official instructions.

### 🎉 Things to Do

A small list of harmless ways to make college life more memorable, from class food parties to taking pictures on the last day of the semester.

Students can heart the activities they like.


## 🎨 Design Philosophy

I didn't want College Hub to look like another generic university dashboard.

Each section uses a different visual metaphor inspired by physical student life:

* 📖 Books and scrapbook pages for resources
* 📌 Notice boards for announcements
* 📝 Paper for notes and rants
* 🗺️ Maps for practical college guidance
* 💌 Personal touches for memories and activities
* ✦ Handwritten-style typography and paper textures throughout

The goal was to make the interface feel **personal, playful, and student-made**, while still keeping the information usable.

## 🚀 Running the Project

Since College Hub is a frontend project, there is no backend setup required.

Clone the repository:

```bash
git clone https://github.com/Amayl97/College-Hub.git
```

Then open the project in your code editor and run it using a local development server such as **VS Code Live Server**.

## 💡 What I Learned

This project pushed me beyond simply making pages that "work."

I focused heavily on:

* Building responsive layouts
* Creating interfaces without relying on frameworks
* Using CSS transforms and 3D perspective
* Creating visual depth with CSS
* Designing interactions with vanilla JavaScript
* Structuring reusable data-driven content
* Thinking about UX rather than only implementation
* Turning ordinary college information into an experience

Most importantly, I learned that a student project doesn't have to look like a typical student project.

The design can communicate the personality of the people it's made for.

## 🎓 Built From a Student's Perspective

College Hub isn't intended to be an official college portal.

It's a **student-made interpretation of what a useful college space could look like**.

The project is based on the idea that students shouldn't have to figure everything out alone.
